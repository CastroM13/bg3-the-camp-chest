No game content is hosted or distributed

The Camp Chest repository and website contain only the project's own code (plus the open-source libraries listed in THIRD_PARTY_NOTICES.md). They contain no game assets, models, textures, icons, text, localisation, or data extracted from Baldur's Gate 3.

When you use the site, it asks your browser for read-only access to a folder that you pick: your own, legally obtained installation of the game. Everything you see (item names, descriptions, stats, 3D models, textures, dyes and poses) is read from that folder at runtime, locally in your browser. The site is designed so that:

  • game files are not uploaded anywhere;
  • game content is not stored or cached on any server we run, and is not sent to us or to anyone else;
  • game content is not redistributed to other users. Each visitor only ever sees content read from their own copy.

The browser may keep the folder permission and temporary data on your own computer (for example in the browser's storage) so the site can start faster next time. You can remove it at any time with "Change game folder" or by clearing the site's data in your browser settings. That local data is never sent anywhere.

We believe this "bring your own game" approach respects the rights of the game's creators, because the site cannot be used without owning the game and it does not give anyone content they do not already have.
